# System-IBPH
Sistema desenvolvido para IBPH - Instituto Brasileiro de Performance Humana

### SOBRE O SISTEMA

O IBPH solicitou o desenvolvimento de um sistema que permitisse ao aministrador e usuário terem acesso aos gráficos dos resultados obtidos por meio da síntese da questões psiquícas.

Os resultados são inseridos no banco de dados por meio de outro sistema. Neste, os dados são resgatados de cada indivíduo alimentando os gráficos correspondentes. Abaixo é discriminado o resultado em uma tabela.

Perguntas foram acrescentadas de forma que o usuário possa responder para outra devolutiva.
Também foi inserido o envio de e-mail por meio de um formulário permitindo uma comunicação entre usuário e IBPH.
